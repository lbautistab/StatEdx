El Teorema del Límite Central

Toma muestras de una población con cualquier forma, calcula su media y repite. Las medias forman una campana cada vez más estrecha. Aquí vas a ver por qué y a medir cuánto se estrecha.

§ 1La idea

Imagina que mides el tiempo de espera de 30 clientes en una fila y calculas el promedio. Mañana mides a otros 30 y obtienes otro promedio, un poco distinto. Si repitieras el experimento mil veces, ¿qué forma tendría la lista de promedios?

La sorpresa es que casi no importa cómo se distribuyen los tiempos individuales. Pueden ser muy asimétricos, como suelen ser los tiempos de espera, y aun así los promedios se agrupan en una campana alrededor de la media real. Esa campana se llama distribución muestral de la media.

Lo que vas a comprobar: la forma de la campana no depende de la población, su centro es la media de la población y su ancho se reduce como \(1/\sqrt{n}\).

§ 2Laboratorio

Elige una población y un tamaño de muestra. El simulador toma 2 000 muestras, calcula la media de cada una y dibuja el histograma de esas medias. La curva es la normal que predice el teorema.

§ 3La fórmula

Sean \(X_1, X_2, \dots, X_n\) variables aleatorias independientes con la misma distribución, media \(\mu\) y varianza finita \(\sigma^2\). Su media muestral es

\[ \bar{X}_n = \frac{1}{n}\sum_{i=1}^{n} X_i . \]

El teorema dice que, al estandarizarla, se acerca a una normal estándar cuando \(n\) crece:

\[ Z_n = \frac{\bar{X}_n - \mu}{\sigma/\sqrt{n}} \;\xrightarrow{\;d\;}\; \mathcal{N}(0,1) \qquad \text{cuando } n \to \infty . \]
El denominador \(\sigma/\sqrt{n}\) es el error estándar: la desviación típica de las medias que mediste en el laboratorio.

Dos consecuencias prácticas:

  • Para cuadruplicar la precisión de un promedio necesitas 16 veces más datos, porque el error estándar baja con la raíz de \(n\).
  • Con \(n \ge 30\) la aproximación suele ser buena, pero poblaciones muy asimétricas (como la exponencial) piden más. Compruébalo arriba.

§ 4Intervalos de confianza

Si las medias siguen una normal, podemos construir un intervalo que capture la media real con una probabilidad conocida:

\[ \bar{x} \;\pm\; z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \]

“95 % de confianza” no significa que este intervalo tenga 95 % de probabilidad de contener a \(\mu\). Significa que, si repites el procedimiento muchas veces, el 95 % de los intervalos la contienen. El simulador dibuja 50 intervalos con muestras de tamaño 25 de una población con \(\mu = 50\) y \(\sigma = 10\).

§ 5En R y Python

Este es el mismo experimento del laboratorio en pocas líneas. Cambia n y compara la desviación de las medias con \(\sigma/\sqrt{n}\).

import numpy as np

rng = np.random.default_rng(7)
n, k = 30, 2_000                 # tamaño de muestra, número de muestras

# población exponencial con media 2 y desviación 2
muestras = rng.exponential(scale=2, size=(k, n))
medias = muestras.mean(axis=1)

print(f"media de las medias: {medias.mean():.3f}")   # ≈ 2
print(f"desv. de las medias: {medias.std():.3f}")    # ≈ 2/√30 ≈ 0.365
set.seed(7)
n <- 30; k <- 2000              # tamaño de muestra, número de muestras

# población exponencial con media 2 y desviación 2
medias <- replicate(k, mean(rexp(n, rate = 1/2)))

cat("media de las medias:", round(mean(medias), 3), "\n")   # ≈ 2
cat("desv. de las medias:", round(sd(medias), 3), "\n")     # ≈ 2/√30 ≈ 0.365

hist(medias, breaks = 40, freq = FALSE, main = "Medias de 2 000 muestras")
curve(dnorm(x, 2, 2 / sqrt(n)), add = TRUE, lwd = 2)

§ 7Ejercicios propuestos

Intenta resolverlos antes de abrir la solución. Los de simulación los puedes correr en R o en Python.

Ejercicio 1Básico

Una población tiene μ = 50 y σ = 12. Si tomas muestras de tamaño n = 36, ¿cuál es el error estándar de la media?

Ver solución

SE = σ/√n = 12/√36 = 12/6 = 2.

Ejercicio 2Básico

Con los datos del ejercicio 1, ¿cuál es la probabilidad de que una muestra de 36 tenga media mayor que 53?

Ver solución

z = (53 − 50)/2 = 1,5. P(Z > 1,5) = 1 − Φ(1,5) ≈ 0,067, es decir, cerca del 6,7 %.

Ejercicio 3Intermedio

El tiempo de atención en un banco es exponencial con media 4 minutos (y σ = 4). Si observas a 64 clientes, ¿qué probabilidad hay de que el tiempo promedio sea menor que 3,5 minutos? Compruébalo con una simulación.

Ver solución

SE = 4/√64 = 0,5. z = (3,5 − 4)/0,5 = −1, así que P ≈ Φ(−1) ≈ 0,159. La simulación debería dar un valor cercano.

import numpy as np
rng = np.random.default_rng(1)
medias = rng.exponential(4, size=(100000, 64)).mean(axis=1)
print((medias < 3.5).mean())   # ≈ 0.158
set.seed(1)
medias <- replicate(100000, mean(rexp(64, rate = 1/4)))
mean(medias < 3.5)   # ≈ 0.158

La simulación da cerca de 0,158: la aproximación normal es muy buena con n = 64, aunque la exponencial sea asimétrica.

Ejercicio 4Desafío

Simula el promedio de lanzar un dado n = 1, 2, 5 y 30 veces, repitiendo 10 000 veces cada caso. Para cada n, compara la desviación de los promedios con σ/√n, donde σ ≈ 1,708.

Ver solución

Deberías obtener aproximadamente 1,708; 1,208; 0,764 y 0,312. El histograma pasa de plano (n = 1) a triangular (n = 2) y a campana (n = 30).

import numpy as np
rng = np.random.default_rng(0)
for n in [1, 2, 5, 30]:
    prom = rng.integers(1, 7, size=(10000, n)).mean(axis=1)
    print(n, round(prom.std(), 3), round(1.708 / np.sqrt(n), 3))
set.seed(0)
for (n in c(1, 2, 5, 30)) {
  prom <- replicate(10000, mean(sample(1:6, n, replace = TRUE)))
  cat(n, round(sd(prom), 3), round(1.708 / sqrt(n), 3), "\n")
}
