§ 1Introducción

Imagina que tienes que estimar la altura media de una cordillera, pero está cubierta de niebla: solo puedes saber la altura del punto donde estás parado y comparar con la de un punto cercano. Una estrategia es caminar al azar, pero aceptando más a menudo los pasos hacia arriba que hacia abajo. Si lo haces bien, pasarás más tiempo en las zonas altas, justo en proporción a su altura. Eso es, en esencia, MCMC.

En inferencia bayesiana casi todo lo que quieres es una integral sobre la posterior: una media, una probabilidad, un intervalo. En la sesión de inferencia bayesiana esas integrales tenían fórmula porque el prior era conjugado. Pero basta una regresión logística con tres predictores, o un modelo jerárquico, para que la posterior viva en muchas dimensiones y su constante \(p(y)\) sea una integral imposible de calcular.

Un poco de historia. En 1953, Nicholas Metropolis, Arianna y Marshall Rosenbluth, y Augusta y Edward Teller publicaron en Los Álamos un método para simular el equilibrio de un sistema de partículas con la computadora MANIAC: proponer un movimiento al azar y aceptarlo según el cociente de probabilidades de Boltzmann. W. Keith Hastings generalizó el algoritmo en 1970 para propuestas asimétricas. En 1984, Stuart y Donald Geman introdujeron el muestreo de Gibbs para restaurar imágenes. Pero la estadística no lo adoptó en masa hasta que Alan Gelfand y Adrian Smith (1990) mostraron que resolvía de forma general los cálculos bayesianos; poco después aparecieron BUGS y JAGS. Hamiltonian Monte Carlo llegó desde la física de partículas (Duane y colaboradores, 1987), y el sampler NUTS de Hoffman y Gelman (2014) lo volvió automático en Stan, hoy el estándar junto con PyMC.

La idea central: MCMC (Monte Carlo por cadenas de Markov) construye una sucesión de valores en la que cada uno depende solo del anterior, diseñada para que, a largo plazo, la sucesión se distribuya como la posterior. Para lograrlo solo necesita evaluar la posterior hasta una constante: verosimilitud por prior.
En esta sesión aprenderás a:
  • Aproximar integrales posteriores con Monte Carlo y medir su error.
  • Entender estacionariedad, ergodicidad y balance detallado en cadenas de Markov.
  • Programar Metropolis-Hastings, demostrar por qué funciona y ajustar el tamaño de paso.
  • Derivar condicionales completas y programar un muestreador de Gibbs.
  • Diagnosticar convergencia con trazas, \(\hat R\), autocorrelación y tamaño efectivo de muestra.
  • Reconocer cuándo pasar a Hamiltonian Monte Carlo y qué diagnósticos extra ofrece.

§ 2Definición

Dos ideas se combinan en el nombre. La primera es Monte Carlo: si tuvieras muestras \(\theta^{(1)}, \dots, \theta^{(S)}\) de \(p(\theta \mid y)\), aproximarías cualquier esperanza con un promedio:

\[ E[h(\theta) \mid y] = \int h(\theta)\,p(\theta \mid y)\,d\theta \;\approx\; \hat h_S = \frac{1}{S}\sum_{s=1}^{S} h\big(\theta^{(s)}\big) \]
Con \(h(\theta) = \theta\) obtienes la media posterior; con \(h(\theta) = \mathbb{1}[\theta > c]\), la probabilidad \(P(\theta > c \mid y)\); los cuantiles de la muestra dan intervalos. Si las muestras son independientes, por el teorema del límite central el error es \(\operatorname{sd}(h)/ \sqrt{S}\), sin importar la dimensión de \(\theta\).

La segunda es la cadena de Markov, la forma de obtener esas muestras cuando no se puede muestrear directamente.

Definición (cadena de Markov y MCMC). Una cadena de Markov es una sucesión \(\theta^{(0)}, \theta^{(1)}, \dots\) tal que \(P(\theta^{(t+1)} \in A \mid \theta^{(0)}, \dots, \theta^{(t)}) = P(\theta^{(t+1)} \in A \mid \theta^{(t)})\), determinada por un núcleo de transición \(T(\theta' \mid \theta)\). Una distribución \(\pi\) es estacionaria para \(T\) si \(\pi(\theta') = \int T(\theta' \mid \theta)\, \pi(\theta)\,d \theta\). Un algoritmo MCMC para \(\pi(\theta) = p(\theta \mid y)\) es un núcleo \(T\) que tiene a \(\pi\) como distribución estacionaria y bajo el cual la cadena converge a ella desde cualquier punto de partida.
  • Calentamiento (warmup o burn-in): iteraciones iniciales que se descartan porque todavía reflejan el punto de partida.
  • Mezcla: qué tan rápido la cadena “olvida” dónde estaba y recorre toda la distribución.
  • Tasa de aceptación: fracción de propuestas aceptadas en Metropolis-Hastings.

Ejemplo numérico: una cadena de dos estados. Un servidor está “libre” (L) u “ocupado” (O). Si está libre, al minuto siguiente sigue libre con probabilidad 0,9; si está ocupado, se libera con probabilidad 0,3. La matriz de transición y la estacionaria cumplen

\[ T = \begin{pmatrix} 0{,}9 & 0{,}1 \\ 0{,}3 & 0{,}7 \end{pmatrix}, \qquad \pi T = \pi \;\Rightarrow\; 0{,}1\,\pi_L = 0{,}3\,\pi_O \;\Rightarrow\; \pi = (0{,}75;\ 0{,}25) \]
Desde “ocupado”, la probabilidad de estar libre es 0,3 tras un paso, 0,48 tras dos, 0,588 tras tres y se acerca a 0,75 como \(0{,}75 - 0{,}75(0{,}6)^t\): el segundo valor propio de \(T\), 0,6, controla la velocidad de convergencia. Si simulas la cadena un millón de minutos, el 75 % del tiempo estará libre, cualquiera que sea el estado inicial.

§ 3Cadenas de Markov: estacionariedad, ergodicidad y balance detallado

Para que MCMC funcione, el núcleo debe cumplir tres condiciones:

  • Estacionariedad: \(\pi\) es invariante bajo \(T\).
  • Irreducibilidad: desde cualquier punto, la cadena puede llegar con probabilidad positiva a cualquier región con \(\pi(A) > 0\).
  • Aperiodicidad: no queda atrapada en ciclos determinísticos (por ejemplo, alternar siempre entre dos regiones).
Teorema ergódico. Si la cadena es irreducible, aperiódica y tiene distribución estacionaria \(\pi\), entonces la distribución de \(\theta^{(t)}\) converge a \(\pi\) desde casi cualquier punto inicial, y para toda \(h\) con \(E_ \pi|h| < \infty\), \(\hat h_S = \frac{1}{S} \sum_{s=1}^S h(\theta^{(s)}) \to E_ \pi[h]\) con probabilidad 1. Bajo condiciones adicionales de mezcla vale además un TLC: \(\sqrt{S}(\hat h_S - E_ \pi h) \to \mathcal{N}(0, \sigma_h^2\, \tau)\), con \(\tau = 1 + 2 \sum_{k \ge 1} \rho_k\) el tiempo de autocorrelación integrado.

¿Cómo se diseña \(T\) para que su distribución estacionaria sea justo la posterior? La condición suficiente más usada es el balance detallado (reversibilidad):

\[ \pi(\theta)\,T(\theta' \mid \theta) = \pi(\theta')\,T(\theta \mid \theta') \quad \text{para todo } \theta, \theta' \]
El flujo de probabilidad de \(\theta\) a \(\theta'\) es igual al flujo de vuelta. Es suficiente pero no necesario: hay algoritmos válidos no reversibles.

Demostración de que balance detallado implica estacionariedad. Integra ambos lados respecto a \(\theta\):

\[ \int \pi(\theta)\,T(\theta' \mid \theta)\,d\theta = \int \pi(\theta')\,T(\theta \mid \theta')\,d\theta = \pi(\theta')\underbrace{\int T(\theta \mid \theta')\,d\theta}_{=1} = \pi(\theta') \]
El lado izquierdo es la distribución de \(\theta^{(t+1)}\) cuando \(\theta^{(t)} \sim \pi\). Que sea igual a \(\pi\) es justo la definición de estacionaria. En la cadena de dos estados: \(\pi_L T_{LO} = 0{,}75 \times 0{,}1 = 0{,}075 = 0{,}25 \times 0{,}3 = \pi_O T_{OL}\).

Dos consecuencias prácticas: las muestras son dependientes (cada una se parece a la anterior), así que valen menos que muestras independientes, en un factor \(\tau\); y los primeros valores reflejan el punto de partida, no la posterior, por eso se descarta un calentamiento.

§ 4El algoritmo de Metropolis-Hastings

Sea \(\tilde p(\theta) = p(y \mid \theta)\,p(\theta)\) la posterior sin normalizar y \(q(\theta^* \mid \theta)\) una distribución de propuesta de la que sí sabes muestrear. En cada iteración \(t\):

  1. Propón \(\theta^* \sim q(\cdot \mid \theta^{(t)})\).
  2. Calcula la razón de aceptación \( r = \dfrac{\tilde p(\theta^*)\; q(\theta^{(t)} \mid \theta^*)}{\tilde p(\theta^{(t)})\; q(\theta^* \mid \theta^{(t)})} \).
  3. Con probabilidad \(\min(1, r)\) acepta: \(\theta^{(t+1)} = \theta^*\). Si no, quédate: \(\theta^{(t+1)} = \theta^{(t)}\).
\[ \alpha(\theta^* \mid \theta) = \min\!\left(1,\ \frac{p(y\mid\theta^*)\,p(\theta^*)}{p(y\mid\theta)\,p(\theta)}\cdot\frac{q(\theta \mid \theta^*)}{q(\theta^* \mid \theta)}\right) \]
La constante \(p(y)\) aparece arriba y abajo y se cancela. Si la propuesta es simétrica, \(q(\theta^* \mid \theta) = q(\theta \mid \theta^*)\) (por ejemplo, \(\theta^* = \theta + \varepsilon\) con \(\varepsilon \sim \mathcal{N}(0, \delta^2)\)), el segundo cociente vale 1 y tienes el algoritmo de Metropolis de paseo aleatorio. Si \(q(\theta^* \mid \theta) = q(\theta^*)\) no depende del estado, es el muestreador independiente.

Teorema. El núcleo de Metropolis-Hastings satisface balance detallado respecto a \(\pi = p(\theta \mid y)\). Demostración: para \(\theta \ne \theta'\), \(T(\theta' \mid \theta) = q(\theta' \mid \theta)\, \alpha(\theta' \mid \theta)\). Entonces

\[ \pi(\theta)\,q(\theta'\mid\theta)\,\min\!\Big(1, \frac{\pi(\theta')q(\theta\mid\theta')}{\pi(\theta)q(\theta'\mid\theta)}\Big) = \min\big(\pi(\theta)q(\theta'\mid\theta),\ \pi(\theta')q(\theta\mid\theta')\big) \]
El lado derecho es simétrico en \(\theta\) y \(\theta'\), así que es igual a \(\pi(\theta')T(\theta \mid \theta')\). Para \(\theta = \theta'\) la igualdad es trivial. Como el cociente usa \(\pi\) solo a través de un cociente, basta conocer \(\tilde p\).

Ejemplo resuelto a mano. Objetivo \(\tilde p(\theta) = e^{- \theta^2/2}\) (una normal estándar sin normalizar), propuesta \(\theta^* = \theta + \varepsilon\), punto de partida \(\theta^{(0)} = 1\). Supón que el generador produce estas propuestas y uniformes:

Error común: descartar las iteraciones rechazadas. Cuando se rechaza, el valor actual se repite en la cadena: esa repetición es la que da más peso a las zonas de alta probabilidad. Si solo guardas los valores aceptados, la muestra queda sesgada.

En la práctica se trabaja con logaritmos para evitar desbordamientos: se acepta si \(\log u < \log \tilde p(\theta^*) - \log \tilde p(\theta^{(t)})\), con \(u \sim \text{Uniforme}(0,1)\). Y si un parámetro está restringido (una varianza, una tasa), se propone en una escala transformada como \(\log \sigma\), recordando incluir el jacobiano (ver priors), o se rechazan las propuestas fuera del soporte.

§ 5Muestreo de Gibbs

Cuando el parámetro tiene varias componentes, \(\theta = (\theta_1, \dots, \theta_d)\), y sabes muestrear de cada condicional completa \(p(\theta_j \mid \theta_{-j}, y)\) (la distribución de una componente dado el resto y los datos), puedes actualizar una componente a la vez:

\[ \theta_1^{(t+1)} \sim p\big(\theta_1 \mid \theta_2^{(t)}, \dots, \theta_d^{(t)}, y\big), \quad \theta_2^{(t+1)} \sim p\big(\theta_2 \mid \theta_1^{(t+1)}, \theta_3^{(t)}, \dots, y\big), \quad \dots \]
Cada paso de Gibbs es un caso particular de Metropolis-Hastings cuya propuesta es la propia condicional completa. Con \(q(\theta_j^* \mid \theta) = \pi(\theta_j^* \mid \theta_{-j})\) y \(\pi(\theta) = \pi(\theta_j \mid \theta_{-j}) \pi(\theta_{-j})\), la razón \(r\) \(= \frac{\pi(\theta_j^* \mid \theta_{-j}) \pi(\theta_{-j})\, \pi(\theta_j \mid \theta_{-j})}{\pi(\theta_j \mid \theta_{-j}) \pi(\theta_{-j})\, \pi(\theta_j^* \mid \theta_{-j})}\) \(= 1\): siempre se acepta. No hay paso que ajustar.

Cómo encontrar una condicional completa. Escribe la posterior conjunta sin normalizar, quédate solo con los factores que contienen \(\theta_j\) y reconoce el núcleo de una distribución conocida. Las condicionales suelen ser fáciles cuando el modelo es condicionalmente conjugado. El ejemplo clásico es la normal con media y varianza desconocidas y priors semiconjugados \(\mu \sim \mathcal{N}(m_0, s_0^2)\), \(\sigma^2 \sim \text{Gamma-Inv}(a_0, b_0)\). La conjunta es

\[ p(\mu, \sigma^2 \mid y) \propto (\sigma^2)^{-n/2}e^{-\sum(y_i - \mu)^2/(2\sigma^2)}\; e^{-(\mu - m_0)^2/(2s_0^2)}\; (\sigma^2)^{-a_0-1}e^{-b_0/\sigma^2} \]
Como función de \(\mu\) (con \(\sigma^2\) fijo) es el producto Normal-Normal de la sesión de priors; como función de \(\sigma^2\) (con \(\mu\) fijo) es \((\sigma^2)^{-(a_0 + n/2) - 1}e^{-[b_0 + \frac12 \sum(y_i- \mu)^2]/ \sigma^2}\), el núcleo de una Gamma inversa.
\[ \mu \mid \sigma^2, y \sim \mathcal{N}\!\left(\frac{m_0/s_0^2 + n\bar y/\sigma^2}{1/s_0^2 + n/\sigma^2},\ \frac{1}{1/s_0^2 + n/\sigma^2}\right), \qquad \sigma^2 \mid \mu, y \sim \text{Gamma-Inv}\!\left(a_0 + \frac{n}{2},\ b_0 + \frac{1}{2}\sum_{i}(y_i - \mu)^2\right) \]
Alternarlas da muestras de la posterior conjunta \(p(\mu, \sigma^2 \mid y)\), aunque esa conjunta no sea de ninguna familia conocida (con priors semiconjugados no lo es). Es el ejemplo resuelto de la sección 10.

Para la normal bivariada del laboratorio, las condicionales son \(\theta_1 \mid \theta_2 \sim \mathcal{N}(\rho\, \theta_2,\ 1- \rho^2)\) y lo simétrico para \(\theta_2\). Si sigues solo \(\theta_1\) en Gibbs, resulta un AR(1): \(\theta_1^{(t+1)} = \rho^2 \theta_1^{(t)} + \text{ruido}\), con autocorrelación \(\rho^2\). Con \(\rho = 0{,}95\), \(\rho^2 = 0{,}9025\) y el ESS por iteración es \((1 - 0{,}9025)/(1 + 0{,}9025) = 0{,}05\): Gibbs sufre con parámetros muy correlacionados. Las soluciones son reparametrizar (por ejemplo, centrar los predictores en una regresión) o actualizar los parámetros correlacionados en bloque.

Variantes útiles. Metropolis dentro de Gibbs: si una condicional no es conocida, se actualiza esa componente con un paso de Metropolis y las demás con Gibbs. Aumento de datos: se agregan variables latentes (por ejemplo, la componente de una mezcla a la que pertenece cada dato) para que todas las condicionales sean sencillas.

§ 6Diagnóstico de convergencia y Hamiltonian Monte Carlo

Ninguna prueba demuestra que una cadena convergió; los diagnósticos solo detectan problemas. Por eso se corren varias cadenas (al menos 4) desde puntos de partida dispersos y se comprueba que todas cuentan la misma historia.

  • Trazas: las cadenas deben verse como “orugas peludas” superpuestas, sin tendencias ni cadenas separadas.
  • \(\hat R\) (Gelman-Rubin, 1992) compara la varianza entre cadenas con la varianza dentro de cada cadena. Con \(m\) cadenas de \(n\) iteraciones, \(W\) el promedio de las varianzas internas y \(B = \frac{n}{m-1} \sum_j(\bar \theta_j - \bar \theta)^2\):
\[ \hat V = \frac{n-1}{n}\,W + \frac{1}{n}\,B, \qquad \hat R = \sqrt{\frac{\hat V}{W}} \]
\(\hat V\) sobreestima la varianza posterior si las cadenas aún no se mezclaron (por \(B\)), y \(W\) la subestima (cada cadena no ha recorrido todo). Si todas exploran la misma distribución, \(B/n\) es pequeño y \(\hat R \approx 1\). La recomendación actual (Vehtari y colaboradores, 2021) es usar la versión dividida y normalizada por rangos, y exigir \(\hat R < 1{,}01\).
  • Tamaño efectivo de muestra (ESS): cuántas muestras independientes equivalen a tus \(S\) muestras autocorrelacionadas. Con autocorrelaciones \(\rho_k\) en el retardo \(k\):
\[ \text{ESS} = \frac{S}{1 + 2\sum_{k=1}^{\infty}\rho_k}, \qquad \text{EEMC}(\bar\theta) = \frac{\operatorname{sd}(\theta \mid y)}{\sqrt{\text{ESS}}} \]
Viene de \(\operatorname{Var}(\bar \theta) = \frac{\sigma^2}{S} \big[1 + 2 \sum_{k=1}^{S-1}(1 - k/S) \rho_k \big]\). Para una cadena AR(1) con \(\rho_k = \phi^k\), la suma geométrica da \(1 + 2 \phi/(1- \phi) = (1+ \phi)/(1- \phi)\) y \(\text{ESS} = S\, \frac{1- \phi}{1+ \phi}\): con \(\phi = 0{,}9\), 10 000 iteraciones valen solo 526 muestras independientes. Busca al menos unos cientos de ESS por parámetro.

Hamiltonian Monte Carlo. El paseo aleatorio escala mal: en 100 dimensiones, una propuesta al azar casi siempre apunta hacia zonas de baja probabilidad, y el paso tiene que ser diminuto. HMC agrega un “momento” \(\mathbf{p} \sim \mathcal{N}(\mathbf{0}, \mathbf{M})\) y simula la dinámica de una partícula con energía potencial \(U(\theta) = - \log \tilde p(\theta)\):

\[ H(\theta, \mathbf{p}) = U(\theta) + \tfrac12\mathbf{p}^\top\mathbf{M}^{-1}\mathbf{p}, \qquad \frac{d\theta}{dt} = \mathbf{M}^{-1}\mathbf{p}, \qquad \frac{d\mathbf{p}}{dt} = \nabla_\theta \log\tilde p(\theta) \]
La trayectoria se integra con el método leapfrog (pasos \(\epsilon\), \(L\) veces) y el punto final se acepta con probabilidad \(\min(1, e^{H_{\text{inicio}} - H_{\text{final}}})\). Como la dinámica exacta conserva \(H\), la aceptación es alta aunque el salto sea largo. El gradiente guía a la cadena por la forma de la posterior.
  • NUTS (No-U-Turn Sampler) elige automáticamente la longitud de cada trayectoria (se detiene cuando la partícula empieza a regresar) y adapta \(\epsilon\) y \(\mathbf{M}\) durante el calentamiento. Es el algoritmo por defecto de Stan (desde R con brms, rstanarm o cmdstanr) y de PyMC y NumPyro en Python.
  • HMC da un diagnóstico extra muy valioso: las transiciones divergentes, que avisan de regiones de curvatura extrema (como el “embudo” de los modelos jerárquicos) que la cadena no puede explorar bien.
  • Requiere parámetros continuos y derivables: los discretos se marginalizan o se muestrean con otros métodos.
Buenas prácticas: descarta la primera mitad como calentamiento (es lo que hace Stan por defecto), revisa \(\hat R\), ESS (en el centro y en las colas) y divergencias de todos los parámetros, y no adelgaces (thinning) las cadenas para “quitar autocorrelación”: tirar iteraciones siempre reduce la información, solo sirve para ahorrar memoria.

§ 7Propiedades

  1. Balance detallado implica estacionariedad. \(\pi(\theta)T(\theta' \mid \theta) = \pi(\theta')T(\theta \mid \theta') \Rightarrow \int \pi(\theta)T(\theta' \mid \theta)d \theta = \pi(\theta')\). Demostración: sección 3.
  2. MH es reversible respecto a la posterior. \(\pi(\theta)q(\theta' \mid \theta) \alpha(\theta' \mid \theta) = \min\{\pi(\theta)q(\theta' \mid \theta), \pi(\theta')q(\theta \mid \theta')\}\), simétrico. Demostración: sección 4.
  3. Solo se necesita la posterior sin normalizar. \(\alpha\) depende de \(\pi\) a través de \(\pi(\theta^*)/ \pi(\theta)\), donde \(p(y)\) se cancela.
  4. Gibbs acepta siempre. Con la condicional completa como propuesta, \(r = 1\). Demostración: sección 5.
  5. Ley de grandes números y TLC para cadenas. \(\hat h_S \to E_ \pi h\) y \(\operatorname{Var}(\hat h_S) \approx \sigma_h^2\, \tau/S\), con \(\tau = 1 + 2 \sum \rho_k\). Justificación: teorema ergódico y TLC para cadenas geométricamente ergódicas.
  6. ESS de un AR(1). \(\text{ESS} = S(1- \phi)/(1+ \phi)\). Demostración: suma geométrica \(\sum_{k \ge 1} \phi^k = \phi/(1- \phi)\).
  7. Escala óptima del paseo aleatorio. Para objetivos aproximadamente normales en dimensión \(d\), \(\delta^* \approx 2{,}38/ \sqrt{d}\) veces la desviación posterior, con aceptación 0,234 cuando \(d\) es grande. Justificación: límite de difusión de Roberts, Gelman y Gilks (1997).
  8. Composición de núcleos. Si \(T_1\) y \(T_2\) dejan invariante a \(\pi\), su composición \(T_2 \circ T_1\) también. Justificación: aplicar dos veces la ecuación de estacionariedad. Por eso se pueden combinar pasos de Gibbs, Metropolis y HMC en un mismo algoritmo.

Errores comunes

  • Guardar solo las propuestas aceptadas.
  • Correr una sola cadena y declararla convergida porque “la traza se ve bien”: una cadena atrapada en un modo también se ve bien.
  • Olvidar el jacobiano al proponer en una escala transformada.
  • Confundir número de iteraciones con información: 50 000 iteraciones con ESS de 80 son poca información.
  • Ignorar las advertencias de divergencias de Stan o PyMC.

§ 8Ejercicios de simulación

Laboratorio 1: la cadena en dos dimensiones. El objetivo es una normal bivariada con medias 0, varianzas 1 y correlación \(\rho\); las elipses marcan las regiones de 1, 2 y 3 desviaciones. La cadena parte lejos, en (−3, 3). Con Metropolis, prueba pasos muy chicos y muy grandes y mira la tasa de aceptación y el tamaño efectivo. Luego cambia a Gibbs, que se mueve en zigzag paralelo a los ejes, y sube la correlación a 0,95.

Experimentos guiados

  1. Con Metropolis y \(\rho = 0{,}7\), corre la cadena con \(\delta = 0{,}1\), luego reinicia con \(\delta = 1{,}5\) y con \(\delta = 5\). Anota aceptación y ESS por cada 100 iteraciones.
    Qué deberías observar

    Con \(\delta = 0{,}1\) la aceptación supera el 90 % pero el ESS es diminuto (1 o 2 por cada 100) y tarda cientos de iteraciones en salir de (−3, 3). Con \(\delta = 5\) acepta muy poco y la traza queda en escalones. Cerca de \(\delta = 1{,}5\) la aceptación ronda 30 % a 40 % y el ESS es el mayor.

  2. Fija \(\delta = 1{,}5\) y compara \(\rho = 0\) con \(\rho = 0{,}95\).
    Qué deberías observar

    Con \(\rho = 0{,}95\) la elipse es angosta y casi todas las propuestas que se salen de ella se rechazan: la aceptación cae y el ESS baja varias veces. La propuesta isotrópica no se adapta a la forma de la posterior; HMC o una propuesta con la covarianza correcta lo resolverían.

  3. Cambia a Gibbs con \(\rho = 0{,}5\) y luego \(\rho = 0{,}95\). Mira la forma del recorrido.
    Qué deberías observar

    La aceptación es siempre 100 %. Con \(\rho = 0{,}5\) el zigzag cruza la elipse en pocos pasos; con 0,95 los escalones son diminutos y la cadena avanza lentamente por la diagonal, como predice la autocorrelación \(\rho^2 = 0{,}90\).

  4. Con Metropolis y \(\delta = 1{,}5\), deja correr hasta 2 000 iteraciones y compara la media de \(\theta_1\) con 0.
    Qué deberías observar

    La media se acerca a 0 con un error del orden de \(1/ \sqrt{\text{ESS}}\). Si el ESS es 300, el error típico es cerca de 0,06: no esperes ver exactamente 0,00.

Laboratorio 2: cuatro cadenas y R̂. Cuatro cadenas de Metropolis parten de puntos dispersos. El objetivo puede ser una normal o una mezcla bimodal; el sombreado marca el calentamiento y el panel derecho muestra la autocorrelación.

Experimentos guiados

  1. Objetivo normal, \(\delta = 0{,}2\), 200 iteraciones. Mira \(\hat R\) y las trazas. Luego sube a 4 000 iteraciones.
    Qué deberías observar

    Con 200 iteraciones las cadenas no se juntan y \(\hat R\) sale muy por encima de 1,1. Con 4 000 se superponen y \(\hat R\) baja a cerca de 1,00, aunque el ESS sigue bajo por la alta autocorrelación.

  2. Con 1 000 iteraciones, mueve \(\delta\) entre 0,2 y 8 y observa la autocorrelación de retardo 1 y el ESS total.
    Qué deberías observar

    La autocorrelación baja de casi 1 a valores cercanos a 0,5 o 0,6 alrededor de \(\delta \approx 2{,}4\) y vuelve a subir con pasos enormes, por los rechazos repetidos. El ESS dibuja una curva con máximo intermedio: el compromiso entre mover poco y rechazar mucho.

  3. Cambia al objetivo bimodal con \(\delta = 0{,}3\) y 4 000 iteraciones.
    Qué deberías observar

    Cada cadena se queda en el modo donde empezó. Cada traza por separado parece sana, pero \(\hat R\) es grande: el diagnóstico entre cadenas detecta lo que una sola cadena nunca mostraría.

  4. Con el bimodal, sube \(\delta\) a 4.
    Qué deberías observar

    Ahora las cadenas saltan entre modos y \(\hat R\) vuelve cerca de 1. En problemas reales en muchas dimensiones un paso grande no basta; se usan técnicas como el templado paralelo (pregunta 5).

§ 9Aplicaciones reales

Salud pública: el modelo de Imperial College sobre la COVID-19

Flaxman y colaboradores publicaron en Nature (2020) un modelo bayesiano jerárquico, ajustado con Stan (NUTS), que estimaba el número reproductivo \(R_t\) en 11 países europeos a partir de las muertes diarias y de las fechas de las intervenciones (cierres de escuelas, confinamientos). Con decenas de parámetros, retrasos entre infección y muerte, y efectos compartidos entre países, no había otra forma práctica de obtener la posterior. El modelo concluyó que los confinamientos tuvieron un efecto grande en reducir \(R_t\), con intervalos de credibilidad amplios, y alimentó decisiones de política sanitaria; también generó un debate metodológico sobre la identificabilidad de los efectos de cada intervención, un buen ejemplo de por qué hay que revisar más que \(\hat R\).

Biología: árboles filogenéticos con MrBayes

Reconstruir la historia evolutiva de un grupo de especies a partir de sus secuencias de ADN requiere explorar un espacio de árboles astronómicamente grande (con 20 especies hay más de \(10^{21}\) topologías). Programas como MrBayes (Huelsenbeck y Ronquist, 2001) y BEAST usan MCMC con movimientos que reordenan ramas y con varias cadenas “calentadas” (Metropolis-coupled MCMC) para saltar entre picos. La salida es la probabilidad posterior de cada clado, que los biólogos reportan junto a cada rama. Los diagnósticos estándar del área son las desviaciones estándar entre corridas independientes, la misma lógica de \(\hat R\).

Física: el modelo de Ising

El problema original de Metropolis: un imán modelado como una rejilla de espines \(\pm 1\) cuya probabilidad es \(\propto e^{-E/(kT)}\). Con una rejilla de 100 × 100 hay \(2^{10\,000}\) configuraciones, imposibles de enumerar. El algoritmo propone invertir un espín y acepta según \(e^{- \Delta E/(kT)}\). Al bajar la temperatura por debajo del valor crítico (que Onsager calculó exactamente en 1944 para dos dimensiones) aparece la magnetización espontánea, y la simulación la reproduce. Cerca de la temperatura crítica la mezcla se vuelve lentísima, un fenómeno llamado ralentización crítica que motivó algoritmos de clústeres como el de Swendsen-Wang.

Finanzas: volatilidad estocástica

En los modelos de volatilidad estocástica, los rendimientos diarios \(r_t \sim \mathcal{N}(0, e^{h_t})\) dependen de una log-volatilidad latente que sigue un AR(1), \(h_t = \mu + \phi(h_{t-1} - \mu) + \eta_t\). Con 2 500 días hay 2 500 variables latentes más los parámetros: la verosimilitud no tiene forma cerrada. Kim, Shephard y Chib (1998) propusieron un Gibbs con aumento de datos; hoy se ajusta con HMC. Los resultados típicos para índices bursátiles dan \(\phi\) muy cercano a 1 (entre 0,95 y 0,99), es decir, volatilidad muy persistente, y la posterior de \(h_t\) sirve para calcular el valor en riesgo de una cartera con su incertidumbre. Ver también modelos ARIMA.

Tiempos de entrega (minutos) de 12 pedidos de un restaurante. Queremos la posterior de la media \(\mu\) y la desviación \(\sigma\) con priors \(\mu \sim \mathcal{N}(30, 10^2)\) y \(\sigma^2 \sim \text{Gamma-Inv}(2, 20)\). Corremos un Gibbs con 4 cadenas desde puntos dispersos, calculamos \(\hat R\) y ESS a mano, el error de Monte Carlo y una predictiva posterior.

import numpy as np

y = np.array([31, 27, 35, 29, 42, 33, 30, 38, 26, 34, 37, 32])   # minutos
n, ybar = len(y), y.mean()
m0, s0, a0, b0 = 30, 10, 2, 20          # priors: μ ~ N(30, 10²), σ² ~ Gamma-Inv(2, 20)

def gibbs(n_iter, mu, rng):
    out = np.empty((n_iter, 2))
    for t in range(n_iter):
        # 1. σ² | μ, y ~ Gamma-Inv(a0 + n/2, b0 + SC/2)
        sc = np.sum((y - mu) ** 2)
        s2 = 1 / rng.gamma(a0 + n / 2, 1 / (b0 + sc / 2))
        # 2. μ | σ², y ~ Normal (promedio ponderado por precisión)
        prec = 1 / s0**2 + n / s2
        media = (m0 / s0**2 + n * ybar / s2) / prec
        mu = rng.normal(media, np.sqrt(1 / prec))
        out[t] = mu, s2
    return out

rng = np.random.default_rng(42)
cadenas = np.array([gibbs(3000, m, rng) for m in [0, 20, 50, 100]])
cadenas = cadenas[:, 500:, :]                   # descartamos el calentamiento

def rhat(x):                                    # x: (cadenas, iteraciones)
    m, n = x.shape
    B = n * x.mean(axis=1).var(ddof=1)
    W = x.var(axis=1, ddof=1).mean()
    return np.sqrt(((n - 1) / n * W + B / n) / W)

def ess(x):                                     # una cadena; corta la suma cuando ρk < 0.05
    x = x - x.mean(); n = len(x)
    acf = np.correlate(x, x, 'full')[n - 1:] / (x @ x)
    s = 0
    for k in range(1, n):
        if acf[k] < 0.05: break
        s += acf[k]
    return n / (1 + 2 * s)

mu_s, sd_s = cadenas[:, :, 0], np.sqrt(cadenas[:, :, 1])
print(mu_s.mean(), np.percentile(mu_s, [2.5, 97.5]))   # ≈ 32.8  [30.2, 35.4]
print(sd_s.mean(), np.percentile(sd_s, [2.5, 97.5]))   # ≈ 4.55  [3.2, 6.7]
print(rhat(mu_s), rhat(sd_s))                          # ≈ 1.000  1.000

  }

(a) Con \(q(\theta^* \mid \theta) = q(\theta^*)\), \(r = \frac{\tilde p(\theta^*)q(\theta)}{\tilde p(\theta)q(\theta^*)} = \frac{w(\theta^*)}{w(\theta)}\). Es como un muestreo por importancia secuencial: los puntos con peso \(w\) grande se retienen mucho tiempo.

    lw = logp(th) - q.logpdf(th)

Ver solución

El ESS por iteración crece desde casi 0 (con \(\delta = 0{,}25\)), alcanza su máximo cerca de \(\delta = 2{,}4\) (alrededor de 0,2 a 0,25) con una aceptación cercana al 44 %, y vuelve a caer con pasos grandes porque la cadena se queda quieta. import numpy as np
rng = np.random.default_rng(4)
def ess(x):
    x = x - x.mean(); n = len(x); f = np.fft.rfft(x, 2 * n)
    acf = np.fft.irfft(f * np.conj(f))[:n] / (x @ x)
    s = 0
    for k in range(1, n):
        if acf[k] < 0.05: break
        s += acf[k]
    return n / (1 + 2 * s)
S = 50_000
for d in [0.25, 0.5, 1, 1.5, 2.4, 3, 5, 10]:
    th, acc, out = 0.0, 0, np.empty(S)
    eps, us = rng.normal(0, d, S), np.log(rng.uniform(size=S))
    for t in range(S):
        prop = th + eps[t]
        if us[t] < (th * th - prop * prop) / 2:
            th, acc = prop, acc + 1
        out[t] = th
    print(d, round(acc / S, 2), round(ess(out) / S, 3))

Modelo de Poisson con punto de cambio. Los conteos anuales \(y_1, \dots, y_T\) siguen Poisson(\(\lambda_1\)) hasta el año \(k\) y Poisson(\(\lambda_2\)) después, con priors \(\lambda_j \sim \text{Gamma}(a, b)\) y \(k\) uniforme en \(\{1, \dots, T-1\}\). Ver solución

(a) Con \(S_1(k) = \sum_{t \le k} y_t\) y \(S_2(k) = \sum_{t > k} y_t\): \(\lambda_1 \mid k, y \sim \text{Gamma}(a + S_1(k),\ b + k)\); \(\lambda_2 \mid k, y \sim \text{Gamma}(a + S_2(k),\ b + T - k)\); y \(P(k \mid \lambda_1, \lambda_2, y) \propto \lambda_1^{S_1(k)}e^{-k \lambda_1} \lambda_2^{S_2(k)}e^{-(T-k) \lambda_2}\), una distribución discreta que se normaliza sumando sobre los \(T - 1\) valores. Interpretación crítica: multimodalidad. El objetivo es la mezcla \(0{,}5\, \mathcal{N}(-6, 1) + 0{,}5\, \mathcal{N}(6, 1)\). (a) Corre 4 cadenas de Metropolis con \(\delta = 1\) desde −6, −6, 6 y 6, y calcula \(\hat R\) y la fracción de tiempo en el modo derecho. (b) Corre las 4 desde −6. ¿Qué dice \(\hat R\) ahora? (c) Implementa templado paralelo con dos temperaturas (\(\tilde p\) y \(\tilde p^{0{,}05}\)) y un intercambio cada 10 iteraciones, y compara. ¿Qué lección deja (b)?

Ver solución

(a) Cada cadena se queda en su modo: dos estiman que todo está en −6 y dos en +6. \(\hat R\) es enorme (mayor que 3): el problema se detecta. (b) Las cuatro cadenas cuentan la misma historia equivocada: \(\hat R \approx 1\) y la fracción en el modo derecho es 0. Ningún diagnóstico puede detectar una región que ninguna cadena visitó: por eso los puntos iniciales deben ser dispersos y hay que pensar en la forma de la posterior. (c) La cadena “caliente” con \(\tilde p^{0{,}05}\) cruza fácilmente entre modos; los intercambios trasladan esos saltos a la cadena fría, que pasa cerca del 50 % del tiempo en cada modo.

import numpy as np
rng = np.random.default_rng(6)
def lp(x): return np.logaddexp(-(x + 6) ** 2 / 2, -(x - 6) ** 2 / 2)
def mh(x0, S=5000, d=1.0):
    x, out = x0, np.empty(S)
    for t in range(S):
        p = x + rng.normal(0, d)
        if np.log(rng.uniform()) < lp(p) - lp(x): x = p
        out[t] = x
    return out
def rhat(ch):
    ch = np.array(ch)[:, len(ch[0]) // 2:]; m, n = ch.shape
    B = n * ch.mean(1).var(ddof=1); W = ch.var(1, ddof=1).mean()
    return np.sqrt(((n - 1) / n * W + B / n) / W)
a = [mh(x0) for x0 in (-6, -6, 6, 6)]
b = [mh(-6) for _ in range(4)]
print(rhat(a), np.mean(np.array(a) > 0))     # R̂ grande, 0.5
print(rhat(b), np.mean(np.array(b) > 0))     # R̂ ≈ 1, 0.0: ¡falsa tranquilidad!
# templado paralelo: x[0] fría (β = 1), x[1] caliente (β = 0.1)
x, beta, fria = np.array([-6.0, -6.0]), np.array([1.0, 0.05]), []
for t in range(20_000):
    for j in range(2):
        p = x[j] + rng.normal(0, 1 if j == 0 else 6)
        if np.log(rng.uniform()) < beta[j] * (lp(p) - lp(x[j])): x[j] = p
    if t % 10 == 0 and np.log(rng.uniform()) < (beta[0] - beta[1]) * (lp(x[1]) - lp(x[0])):
        x = x[::-1].copy()
    fria.append(x[0])
print(np.mean(np.array(fria) > 0))           # ≈ 0.5
set.seed(6)
lp <- function(x) log(exp(-(x + 6)^2 / 2) + exp(-(x - 6)^2 / 2))
mh <- function(x0, S = 5000, d = 1) {
  x <- x0; out <- numeric(S)
  for (t in 1:S) { p <- x + rnorm(1, 0, d); if (log(runif(1)) < lp(p) - lp(x)) x <- p; out[t] <- x }
  out
}
rhat <- function(ch) { ch <- ch[-(1:(nrow(ch) / 2)), ]; n <- nrow(ch)
  B <- n * var(colMeans(ch)); W <- mean(apply(ch, 2, var)); sqrt(((n - 1) / n * W + B / n) / W) }
a <- sapply(c(-6, -6, 6, 6), mh); b <- sapply(rep(-6, 4), mh)
c(rhat(a), mean(a > 0)); c(rhat(b), mean(b > 0))
x <- c(-6, -6); beta <- c(1, 0.05); fria <- numeric(20000)
for (t in 1:20000) {
  for (j in 1:2) { p <- x[j] + rnorm(1, 0, c(1, 6)[j])
    if (log(runif(1)) < beta[j] * (lp(p) - lp(x[j]))) x[j] <- p }
  if (t %% 10 == 0 && log(runif(1)) < (beta[1] - beta[2]) * (lp(x[2]) - lp(x[1]))) x <- rev(x)
  fria[t] <- x[1]
}
mean(fria > 0)                                 # ≈ 0.5
