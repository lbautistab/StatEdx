§ 1La idea

Imagina que tienes que estimar la altura media de una cordillera, pero está cubierta de niebla: solo puedes saber la altura del punto donde estás parado y comparar con la de un punto cercano. Una estrategia es caminar al azar, pero aceptando más a menudo los pasos hacia arriba que hacia abajo. Si lo haces bien, pasarás más tiempo en las zonas altas, justo en proporción a su altura. Eso es, en esencia, MCMC.

En inferencia bayesiana casi todo lo que quieres es una integral sobre la posterior: una media, una probabilidad, un intervalo. Si tuvieras muestras \(\theta^{(1)}, \dots, \theta^{(S)}\) de \(p(\theta \mid y)\), las aproximarías con promedios (Monte Carlo):

\[ E[h(\theta) \mid y] = \int h(\theta)\,p(\theta \mid y)\,d\theta \;\approx\; \frac{1}{S}\sum_{s=1}^{S} h\big(\theta^{(s)}\big) \]
Con \(h(\theta) = \theta\) obtienes la media posterior; con \(h(\theta) = \mathbb{1}[\theta > c]\), la probabilidad \(P(\theta > c \mid y)\). El problema es que, fuera de los casos conjugados, no sabes muestrear directamente de \(p(\theta \mid y)\), y ni siquiera conoces su constante \(p(y)\).
La idea central: MCMC (Monte Carlo por cadenas de Markov) construye una sucesión de valores en la que cada uno depende solo del anterior, diseñada para que, a largo plazo, la sucesión se distribuya como la posterior. Para lograrlo solo necesita evaluar la posterior hasta una constante: verosimilitud por prior.

§ 2Cadenas de Markov

Una cadena de Markov es una sucesión \(\theta^{(0)}, \theta^{(1)}, \dots\) en la que la distribución del siguiente estado depende solo del actual, a través de un núcleo de transición \(T(\theta' \mid \theta)\). Una distribución \(\pi\) es estacionaria si, cuando el estado actual sigue \(\pi\), el siguiente también la sigue:

\[ \pi(\theta') = \int T(\theta' \mid \theta)\,\pi(\theta)\,d\theta \]
Si además la cadena es irreducible (puede llegar a cualquier región con probabilidad positiva) y aperiódica (no queda atrapada en ciclos), entonces desde cualquier punto de partida la distribución de \(\theta^{(t)}\) converge a \(\pi\), y los promedios a lo largo de la cadena convergen a las esperanzas bajo \(\pi\) (teorema ergódico).

¿Cómo se diseña \(T\) para que su distribución estacionaria sea justo la posterior? La condición suficiente más usada es el balance detallado (reversibilidad):

\[ \pi(\theta)\,T(\theta' \mid \theta) = \pi(\theta')\,T(\theta \mid \theta') \quad \text{para todo } \theta, \theta' \]
El flujo de probabilidad de \(\theta\) a \(\theta'\) es igual al flujo de vuelta. Integrando ambos lados en \(\theta\) se obtiene la ecuación de estacionariedad. Metropolis-Hastings está construido para cumplir esta igualdad.

Dos consecuencias prácticas: las muestras son dependientes (cada una se parece a la anterior), así que valen menos que muestras independientes; y los primeros valores reflejan el punto de partida, no la posterior, por eso se descarta un calentamiento (warmup o burn-in).

§ 3El algoritmo de Metropolis-Hastings

Sea \(\tilde p(\theta) = p(y \mid \theta)\,p(\theta)\) la posterior sin normalizar y \(q(\theta^* \mid \theta)\) una distribución de propuesta de la que sí sabes muestrear. En cada iteración \(t\):

  1. Propón \(\theta^* \sim q(\cdot \mid \theta^{(t)})\).
  2. Calcula la razón de aceptación \( r = \dfrac{\tilde p(\theta^*)\; q(\theta^{(t)} \mid \theta^*)}{\tilde p(\theta^{(t)})\; q(\theta^* \mid \theta^{(t)})} \).
  3. Con probabilidad \(\min(1, r)\) acepta: \(\theta^{(t+1)} = \theta^*\). Si no, quédate: \(\theta^{(t+1)} = \theta^{(t)}\).
\[ \alpha(\theta^* \mid \theta) = \min\!\left(1,\ \frac{p(y\mid\theta^*)\,p(\theta^*)}{p(y\mid\theta)\,p(\theta)}\cdot\frac{q(\theta \mid \theta^*)}{q(\theta^* \mid \theta)}\right) \]
La constante \(p(y)\) aparece arriba y abajo y se cancela. Si la propuesta es simétrica, \(q(\theta^* \mid \theta) = q(\theta \mid \theta^*)\) (por ejemplo, \(\theta^* = \theta + \varepsilon\) con \(\varepsilon \sim \mathcal{N}(0, \delta^2)\)), el segundo cociente vale 1 y tienes el algoritmo de Metropolis de paseo aleatorio.

Por qué funciona: para \(\theta \ne \theta'\), \(T(\theta' \mid \theta) = q(\theta' \mid \theta)\,\alpha(\theta' \mid \theta)\), y \(\pi(\theta)\,q(\theta'\mid\theta)\,\min(1, r) = \min\big(\pi(\theta)q(\theta'\mid\theta),\ \pi(\theta')q(\theta\mid\theta')\big)\), una expresión simétrica en \(\theta\) y \(\theta'\). Eso es el balance detallado.

Muy pequeñoCercana a 100 %Casi todo se acepta, pero la cadena avanza a pasitos: alta autocorrelación, exploración lentísima.
Adecuado20 % a 50 %Buen equilibrio. Teoría para objetivos normales: óptimo cerca de 44 % en una dimensión y 23,4 % en muchas, con \(\delta \approx 2{,}38\,\sigma/\sqrt{d}\).
Muy grandeCercana a 0 %Las propuestas caen en zonas de baja probabilidad y se rechazan; la cadena se queda quieta muchas iteraciones.
Error común: descartar las iteraciones rechazadas. Cuando se rechaza, el valor actual se repite en la cadena: esa repetición es la que da más peso a las zonas de alta probabilidad. Si solo guardas los valores aceptados, la muestra queda sesgada.

En la práctica se trabaja con logaritmos para evitar desbordamientos: se acepta si \(\log u < \log\tilde p(\theta^*) - \log\tilde p(\theta^{(t)})\), con \(u \sim \text{Uniforme}(0,1)\). Y si un parámetro está restringido (una varianza, una tasa), se propone en una escala transformada como \(\log\sigma\), recordando incluir el jacobiano, o se rechazan las propuestas fuera del soporte.

§ 4Laboratorio: la cadena en dos dimensiones

El objetivo es una normal bivariada con medias 0, varianzas 1 y correlación \(\rho\); las elipses marcan las regiones de 1, 2 y 3 desviaciones. La cadena parte lejos, en (−3, 3). Con Metropolis, prueba pasos muy chicos y muy grandes y mira la tasa de aceptación y el tamaño efectivo. Luego cambia a Gibbs, que se mueve en zigzag paralelo a los ejes, y sube la correlación a 0,95.

§ 5Muestreo de Gibbs

Cuando el parámetro tiene varias componentes, \(\theta = (\theta_1, \dots, \theta_d)\), y sabes muestrear de cada condicional completa \(p(\theta_j \mid \theta_{-j}, y)\) (la distribución de una componente dado el resto y los datos), puedes actualizar una componente a la vez:

\[ \theta_1^{(t+1)} \sim p\big(\theta_1 \mid \theta_2^{(t)}, \dots, \theta_d^{(t)}, y\big), \quad \theta_2^{(t+1)} \sim p\big(\theta_2 \mid \theta_1^{(t+1)}, \theta_3^{(t)}, \dots, y\big), \quad \dots \]
Cada paso de Gibbs es un caso particular de Metropolis-Hastings cuya propuesta es la propia condicional completa: la razón \(r\) vale exactamente 1 y siempre se acepta. No hay paso que ajustar.

Las condicionales completas suelen ser fáciles cuando el modelo es condicionalmente conjugado. El ejemplo clásico es la normal con media y varianza desconocidas y priors semiconjugados \(\mu \sim \mathcal{N}(m_0, s_0^2)\), \(\sigma^2 \sim \text{Gamma-Inv}(a_0, b_0)\):

\[ \mu \mid \sigma^2, y \sim \mathcal{N}\!\left(\frac{m_0/s_0^2 + n\bar y/\sigma^2}{1/s_0^2 + n/\sigma^2},\ \frac{1}{1/s_0^2 + n/\sigma^2}\right), \qquad \sigma^2 \mid \mu, y \sim \text{Gamma-Inv}\!\left(a_0 + \frac{n}{2},\ b_0 + \frac{1}{2}\sum_{i}(y_i - \mu)^2\right) \]
La primera es la actualización Normal-Normal de la clase anterior, tratando \(\sigma^2\) como conocida; la segunda es la actualización conjugada de una varianza con media conocida. Alternarlas da muestras de la posterior conjunta \(p(\mu, \sigma^2 \mid y)\). Es el ejemplo resuelto de la sección 8.

Para la normal bivariada del laboratorio, las condicionales son \(\theta_1 \mid \theta_2 \sim \mathcal{N}(\rho\,\theta_2,\ 1-\rho^2)\) y lo simétrico para \(\theta_2\). Con \(\rho\) cercano a 1, la varianza condicional \(1-\rho^2\) es diminuta y cada paso apenas se mueve: Gibbs sufre con parámetros muy correlacionados. Las soluciones son reparametrizar (por ejemplo, centrar los predictores en una regresión) o actualizar los parámetros correlacionados en bloque.

§ 6Diagnóstico de convergencia

Ninguna prueba demuestra que una cadena convergió; los diagnósticos solo detectan problemas. Por eso se corren varias cadenas (al menos 4) desde puntos de partida dispersos y se comprueba que todas cuentan la misma historia.

  • Trazas: las cadenas deben verse como “orugas peludas” superpuestas, sin tendencias ni cadenas separadas.
  • \(\hat R\) (Gelman-Rubin) compara la varianza entre cadenas con la varianza dentro de cada cadena. Con \(m\) cadenas de \(n\) iteraciones, \(W\) el promedio de las varianzas internas y \(B = \frac{n}{m-1}\sum_j(\bar\theta_j - \bar\theta)^2\):
\[ \hat V = \frac{n-1}{n}\,W + \frac{1}{n}\,B, \qquad \hat R = \sqrt{\frac{\hat V}{W}} \]
Si todas las cadenas exploran la misma distribución, \(B/n\) es pequeño y \(\hat R \approx 1\). La recomendación actual (Vehtari y colaboradores, 2021) es usar la versión dividida y normalizada por rangos, y exigir \(\hat R < 1{,}01\).
  • Tamaño efectivo de muestra (ESS): cuántas muestras independientes equivalen a tus \(S\) muestras autocorrelacionadas. Con autocorrelaciones \(\rho_k\) en el retardo \(k\):
\[ \text{ESS} = \frac{S}{1 + 2\sum_{k=1}^{\infty}\rho_k}, \qquad \text{EEMC}(\bar\theta) = \frac{\operatorname{sd}(\theta \mid y)}{\sqrt{\text{ESS}}} \]
El error estándar de Monte Carlo (EEMC) mide cuánto cambiaría tu estimación si corrieras otra vez el algoritmo. Para una cadena AR(1) con \(\rho_k = \phi^k\), \(\text{ESS} = S\,\frac{1-\phi}{1+\phi}\): con \(\phi = 0{,}9\), 10 000 iteraciones valen solo 526 muestras independientes. Busca al menos unos cientos de ESS por parámetro.
Buenas prácticas: descarta la primera mitad como calentamiento (es lo que hace Stan por defecto), revisa \(\hat R\) y ESS de todos los parámetros, y no adelgaces (thinning) las cadenas para “quitar autocorrelación”: tirar iteraciones siempre reduce la información, solo sirve para ahorrar memoria.

§ 7Más allá: Hamiltonian Monte Carlo y NUTS

El paseo aleatorio escala mal: en 100 dimensiones, una propuesta al azar casi siempre apunta hacia zonas de baja probabilidad, y el paso tiene que ser diminuto. Hamiltonian Monte Carlo (HMC) usa el gradiente de \(\log p(\theta \mid y)\) para proponer movimientos largos que siguen la forma de la posterior, como una pelota que rueda por una superficie sin fricción. Las propuestas lejanas se aceptan con alta probabilidad.

  • NUTS (No-U-Turn Sampler) ajusta solo la longitud de cada trayectoria y el tamaño de paso durante el calentamiento. Es el algoritmo por defecto de Stan (desde R con brms, rstanarm o cmdstanr) y de PyMC y NumPyro en Python.
  • HMC da un diagnóstico extra muy valioso: las transiciones divergentes, que avisan de regiones de curvatura extrema (como el “embudo” de los modelos jerárquicos) que la cadena no puede explorar bien.
  • Requiere parámetros continuos: los discretos se marginalizan o se muestrean con otros métodos.
Para recordar: programar Metropolis o Gibbs a mano es la mejor manera de entender MCMC, pero para análisis reales usa Stan o PyMC. Lo que no cambia es tu responsabilidad: revisar \(\hat R\), ESS, divergencias y trazas antes de interpretar cualquier resultado.

§ 8Ejemplo resuelto en R y Python

Tiempos de entrega (minutos) de 12 pedidos de un restaurante. Queremos la posterior de la media \(\mu\) y la desviación \(\sigma\) con priors \(\mu \sim \mathcal{N}(30, 10^2)\) y \(\sigma^2 \sim \text{Gamma-Inv}(2, 20)\). Corremos un Gibbs con 4 cadenas desde puntos dispersos y calculamos \(\hat R\) y ESS a mano.

import numpy as np

y = np.array([31, 27, 35, 29, 42, 33, 30, 38, 26, 34, 37, 32])   # minutos
n, ybar = len(y), y.mean()
m0, s0, a0, b0 = 30, 10, 2, 20          # priors: μ ~ N(30, 10²), σ² ~ Gamma-Inv(2, 20)

def gibbs(n_iter, mu, rng):
    out = np.empty((n_iter, 2))
    for t in range(n_iter):
        # 1. σ² | μ, y ~ Gamma-Inv(a0 + n/2, b0 + SC/2)
        sc = np.sum((y - mu) ** 2)
        s2 = 1 / rng.gamma(a0 + n / 2, 1 / (b0 + sc / 2))
        # 2. μ | σ², y ~ Normal (promedio ponderado por precisión)
        prec = 1 / s0**2 + n / s2
        media = (m0 / s0**2 + n * ybar / s2) / prec
        mu = rng.normal(media, np.sqrt(1 / prec))
        out[t] = mu, s2
    return out

rng = np.random.default_rng(42)
cadenas = np.array([gibbs(3000, m, rng) for m in [0, 20, 50, 100]])
cadenas = cadenas[:, 500:, :]                   # descartamos el calentamiento

def rhat(x):                                    # x: (cadenas, iteraciones)
    m, n = x.shape
    B = n * x.mean(axis=1).var(ddof=1)
    W = x.var(axis=1, ddof=1).mean()
    return np.sqrt(((n - 1) / n * W + B / n) / W)

def ess(x):                                     # una cadena; corta la suma cuando ρk < 0.05
    x = x - x.mean(); n = len(x)
    acf = np.correlate(x, x, 'full')[n - 1:] / (x @ x)
    s = 0
    for k in range(1, n):
        if acf[k] < 0.05: break
        s += acf[k]
    return n / (1 + 2 * s)

mu_s, sd_s = cadenas[:, :, 0], np.sqrt(cadenas[:, :, 1])
print(mu_s.mean(), np.percentile(mu_s, [2.5, 97.5]))   # ≈ 32.8  [30.2, 35.4]
print(sd_s.mean(), np.percentile(sd_s, [2.5, 97.5]))   # ≈ 4.55  [3.2, 6.7]
print(rhat(mu_s), rhat(sd_s))                          # ≈ 1.000  1.000
print(sum(ess(c) for c in mu_s))                       # ≈ 10 000: casi independientes
print((mu_s > 35).mean())                               # P(μ > 35 | y) ≈ 0.05
y <- c(31, 27, 35, 29, 42, 33, 30, 38, 26, 34, 37, 32)   # minutos
n <- length(y); ybar <- mean(y)
m0 <- 30; s0 <- 10; a0 <- 2; b0 <- 20

gibbs <- function(n_iter, mu) {
  out <- matrix(NA, n_iter, 2, dimnames = list(NULL, c("mu", "s2")))
  for (t in 1:n_iter) {
    sc <- sum((y - mu)^2)
    s2 <- 1 / rgamma(1, shape = a0 + n / 2, rate = b0 + sc / 2)
    prec <- 1 / s0^2 + n / s2
    mu <- rnorm(1, (m0 / s0^2 + n * ybar / s2) / prec, sqrt(1 / prec))
    out[t, ] <- c(mu, s2)
  }
  out
}

set.seed(42)
cadenas <- lapply(c(0, 20, 50, 100), function(m) gibbs(3000, m)[-(1:500), ])
mu_s <- sapply(cadenas, function(ch) ch[, "mu"])            # matriz iteraciones × cadenas
sd_s <- sapply(cadenas, function(ch) sqrt(ch[, "s2"]))

rhat <- function(x) {
  n <- nrow(x)
  B <- n * var(colMeans(x)); W <- mean(apply(x, 2, var))
  sqrt(((n - 1) / n * W + B / n) / W)
}
mean(mu_s); quantile(mu_s, c(0.025, 0.975))   # ≈ 32.8  [30.2, 35.4]
mean(sd_s); quantile(sd_s, c(0.025, 0.975))   # ≈ 4.55  [3.2, 6.7]
c(rhat(mu_s), rhat(sd_s))                         # ≈ 1.000  1.000

# con el paquete coda: ESS y R̂ estándar
library(coda)
mc <- mcmc.list(lapply(1:4, function(j) mcmc(mu_s[, j])))
effectiveSize(mc)                                # ≈ 10 000
gelman.diag(mc)                                  # ≈ 1.00
traceplot(mc)
mean(mu_s > 35)                                  # ≈ 0.05

Cómo leerlo. Las cuatro cadenas parten de 0, 20, 50 y 100 minutos, pero en pocas iteraciones llegan a la misma zona: \(\hat R \approx 1{,}000\). La media posterior de \(\mu\) es 32,8 minutos (IC 95 % de 30,2 a 35,4) y la de \(\sigma\), 4,55. Como en este modelo \(\mu\) y \(\sigma^2\) están casi incorrelacionados a posteriori, Gibbs produce muestras casi independientes y el ESS es prácticamente igual al número de iteraciones. La probabilidad de que la entrega media supere 35 minutos es cercana al 5 %.

§ 10Ejercicios propuestos

Intenta resolverlos antes de abrir la solución. Los tres primeros se hacen con calculadora.

Ejercicio 1Básico

La posterior sin normalizar es \(\tilde p(\theta) = e^{-\theta^2/2}\) y usas una propuesta normal simétrica. El valor actual es \(\theta = 1\). Calcula la probabilidad de aceptar si la propuesta es (a) \(\theta^* = 2\) y (b) \(\theta^* = 0{,}5\).

Ver solución

(a) \(r = e^{-4/2}/e^{-1/2} = e^{-1{,}5} \approx 0{,}223\): se acepta con probabilidad 0,223. (b) \(r = e^{-0{,}125}/e^{-0{,}5} = e^{0{,}375} \approx 1{,}45 > 1\): se acepta siempre. Los pasos hacia mayor densidad siempre se aceptan; los que bajan, solo a veces.

Ejercicio 2Básico

Cuatro cadenas de 1 000 iteraciones tienen medias 0,10; −0,05; 0,02 y 2,90, y la varianza dentro de cada cadena es 1. Calcula \(\hat R\). ¿Qué está pasando?

Ver solución

\(W = 1\). La varianza de las cuatro medias (con \(m-1\) en el denominador) es 2,073, así que \(B = 1\,000 \times 2{,}073 = 2\,073\). \(\hat V = \frac{999}{1000}\cdot 1 + \frac{2\,073}{1\,000} \approx 3{,}07\) y \(\hat R = \sqrt{3{,}07} \approx\) 1,75. Una cadena está explorando una zona distinta (quizás otro modo o se quedó atascada). Hay que mirar las trazas y no interpretar la posterior.

Ejercicio 3Intermedio

Una cadena se comporta como un AR(1) con autocorrelación \(\phi = 0{,}9\) y la desviación posterior del parámetro es 2. (a) ¿Cuál es el ESS de 10 000 iteraciones? (b) ¿Cuál es el error estándar de Monte Carlo de la media? (c) ¿Cuántas iteraciones necesitas para un EEMC de 0,02?

Ver solución

(a) \(\text{ESS} = 10\,000 \cdot \frac{0{,}1}{1{,}9} \approx\) 526. (b) \(\text{EEMC} = 2/\sqrt{526} \approx\) 0,087. (c) Necesitas \(\text{ESS} = (2/0{,}02)^2 = 10\,000\), es decir, \(10\,000 \times 19 =\) 190 000 iteraciones. Mejorar el muestreador (bajar \(\phi\)) suele ser mucho más barato que alargar la cadena.

Ejercicio 4Desafío

Programa un Metropolis para la tasa \(\lambda\) del centro de llamadas de la clase anterior (prior Gamma(8, 2), 31 llamadas en 5 horas). Ajusta el paso para obtener cerca de 44 % de aceptación y compara la media y el intervalo con la posterior exacta Gamma(39, 7) (media 5,57, IC 95 % de 3,96 a 7,45).

Ver solución

La desviación posterior es cerca de 0,89, así que la regla \(2{,}4\,\sigma\) sugiere un paso cercano a 2. Las propuestas con \(\lambda \le 0\) se rechazan devolviendo \(-\infty\) en la log-posterior. Con paso 2 se acepta alrededor del 46 % y la media resulta ≈ 5,57 con IC ≈ [3,9 ; 7,4], igual que la solución exacta salvo error de Monte Carlo.

import numpy as np
from scipy import stats

def log_post(lam):
    if lam <= 0:
        return -np.inf
    return stats.gamma.logpdf(lam, 8, scale=1 / 2) + stats.poisson.logpmf(31, 5 * lam)

rng = np.random.default_rng(3)
lam, cadena, acept, paso = 4.0, [], 0, 2.0
for t in range(20000):
    prop = lam + rng.normal(0, paso)
    if np.log(rng.uniform()) < log_post(prop) - log_post(lam):
        lam, acept = prop, acept + 1
    cadena.append(lam)          # se guarda aunque se rechace

cadena = np.array(cadena[2000:])
print(acept / 20000)                                   # ≈ 0.46
print(cadena.mean(), np.percentile(cadena, [2.5, 97.5]))   # ≈ 5.57  [3.9, 7.4]
log_post <- function(lam) {
  if (lam <= 0) return(-Inf)
  dgamma(lam, 8, rate = 2, log = TRUE) + dpois(31, 5 * lam, log = TRUE)
}
set.seed(3)
lam <- 4; paso <- 2; acept <- 0; cadena <- numeric(20000)
for (t in 1:20000) {
  prop <- lam + rnorm(1, 0, paso)
  if (log(runif(1)) < log_post(prop) - log_post(lam)) { lam <- prop; acept <- acept + 1 }
  cadena[t] <- lam
}
cadena <- cadena[-(1:2000)]
acept / 20000                                   # ≈ 0.46
mean(cadena); quantile(cadena, c(0.025, 0.975))   # ≈ 5.57  [3.9, 7.4]
